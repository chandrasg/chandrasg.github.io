The 1,404 released means are data outputs rather than 1,404 independent paper-statistic replications. The 276 numeric table cells are source transcriptions. The histogram recovery, equal-cell diagnostics and printed-p calculations are separate result classes and are not added together into an inflated reproduction count.

The final published supplement is a three-page methods document. Detailed Tables S1/S2 and Figures S1/S2 occur in the distinct nine-page OSF author manuscript. All correspondence claims use the specified version. The source S2 Anger row's keywords duplicate Worry, and a Despair row's keywords duplicate Emptiness-longing; null topic IDs preserve that ambiguity.

BH is applied to two explicitly separate displayed-p families (3 and 23), using monotone adjusted p values and q=.05. Agreement with shading is an arithmetic compatibility result. It does not confirm the original correction family, recover full-precision p values or reproduce the individual regression tests.
